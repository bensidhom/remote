05 · statewide database analyst

Bridgette turns language into audited rows.

The full-page tool generates a guarded read-only SELECT, executes it, exposes the result table, and then streams a plain-language summary.

Question → SQL → rows

How many bridges are in each county?

SELECT c.county_name,
       COUNT(DISTINCT b.bridge_number) AS bridge_count
FROM bridges b
JOIN counties c ON c.state_code=b.state_code
                AND c.county_code=b.county_code
WHERE b.data_year=(SELECT MAX(data_year) FROM bridges)
GROUP BY c.county_name
ORDER BY bridge_count DESC
LIMIT 500;
